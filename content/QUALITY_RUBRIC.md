# GoIngrid - Rúbrica de calidad de contenido

Cada criterio se califica de 0 a 2. Una lección requiere mínimo 18/20 y ningún criterio puede obtener 0.

| Criterio | 0 | 1 | 2 |
|---|---|---|---|
| Objetivo comunicativo | No existe | Poco observable | Observable y demostrable |
| Progresión | Aislada | Parcial | Comprensión, práctica, producción y transferencia |
| Naturalidad | Artificial | Comprensible | Natural y útil |
| Adecuación A1 | Demasiado difícil | Irregular | Carga cognitiva adecuada |
| Hispanohablantes | Ignorados | Mencionados | Practicados explícitamente |
| Escucha | Solo texto | Guion básico | Audio, propósito y comprensión |
| Pronunciación | Repetición superficial | Objetivo débil | Modelo, práctica y feedback |
| Conversación | Respuesta única | Roleplay limitado | Turnos, variación y repreguntas |
| Feedback | Genérico | Parcial | Específico y accionable |
| Transferencia | Ausente | Muy parecida | Situación nueva y relevante |

## Rechazo automático

Se rechaza una lección si todas las actividades usan la misma plantilla, la respuesta depende de una frase arbitraria, se presenta texto como audio, se califica pronunciación como binaria, una tarea abierta se marca automáticamente como correcta, faltan rúbricas de producción o existen caracteres corruptos e instrucciones ambiguas.
