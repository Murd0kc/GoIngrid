# GoIngrid — Estándar de profundidad pedagógica

Este documento es obligatorio para crear, revisar o publicar contenido educativo.

## Regla principal

Ningún tema, lección o actividad se considera completo por tener una cantidad determinada de ejercicios o por pasar una validación técnica. Debe demostrar que el estudiante puede comprender, recordar, producir y transferir el contenido.

## Cobertura obligatoria

Cada tema debe cubrir, cuando corresponda:

- alcance completo del concepto;
- explicación teórica clara en español;
- ejemplos graduados y contraejemplos;
- vocabulario contextual;
- pronunciación y dificultades para hispanohablantes;
- escucha, lectura, escritura y conversación;
- práctica guiada, semiabierta y libre;
- errores típicos y retroalimentación accionable;
- evaluación objetiva, repaso espaciado y transferencia real.

## Puerta de calidad

La cantidad de actividades se decide por cobertura y dominio, no por una cifra fija. Un tema como el alfabeto debe incluir las 26 letras, sus nombres, pronunciación, ejemplos, audio, reconocimiento, producción y uso en situaciones reales.

Antes de publicar contenido se debe generar una matriz de cobertura y verificar que ninguna actividad evalúe un concepto que no haya sido explicado. Las validaciones JSON, SQL y de interfaz son necesarias, pero no sustituyen la revisión pedagógica.

## Aplicación al desarrollo

Toda decisión de contenido, base de datos, frontend o IA debe comprobar este estándar antes de considerarse terminada.
